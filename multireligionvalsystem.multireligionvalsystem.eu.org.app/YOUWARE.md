# Pulse — Mobile App Landing Page

A premium landing page for mobile apps designed to drive downloads with feature showcase and platform download links.

## Project Status

- **Project Type**: React + TypeScript + Vite + Tailwind CSS
- **Design Theme**: Dark luxury with gradient accents (purple/teal/pink)
- **Typography**: Outfit (display) + Space Grotesk (body)
- **Animation**: Framer Motion for scroll reveals, hover effects, floating elements

## Key Features Implemented

### Sections
1. **Sticky Navbar** — Glass-morphism on scroll, mobile responsive with hamburger menu
2. **Hero** — Bold headline with gradient text, phone mockup with floating badges, download CTA + social proof
3. **Stats Bar** — Animated counters (500K+ downloads, 4.9 rating, 50+ countries, 99% satisfaction)
4. **Fred** — Peace and conflict resolution concepts with three pillars (Konfliktlösning, Global Fred, Fredskoncept)
5. **Demokrati** — Democratic development with four principles and stödröstning analysis
6. **Hållbar Utveckling** — Sustainable development goals (Klimatmål, Flyktingströmmen, Bistånd)
7. **Multireligionvalsystem** — CTA section for the multi-religion voting system reform
8. **Footer** — Full footer with product/company/resources/legal links + social icons

### Design Elements
- Gradient mesh background with noise texture overlay
- Glass-morphism cards with subtle borders
- Custom CSS scrollbar styling
- Phone mockup frames with dynamic notch
- Floating animated badges with glow effects
- Section dividers with gradient fades
- Hover micro-interactions on all interactive elements

## Tech Stack
- React 18 + TypeScript
- Vite 7.0 (build tool)
- Tailwind CSS 3.4
- Framer Motion 11 (animations)
- Lucide React (icons)
